# LungMask segmenter (lung/lobe specific)

LungMask segmenter (lung/lobe specific)

## Usage

``` r
ds.segmenter.lungmask(model = "R231")

ds.imaging.segmenter.lungmask(model = "R231")
```

## Arguments

- model:

  Character; "R231", "LTRCLobes", "LTRCLobes_R231", "R231CovidWeb".

## Value

A segmenter spec.
