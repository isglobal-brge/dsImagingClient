# Voxel-based feature map (firstorder only)

Voxel-based feature map (firstorder only)

## Usage

``` r
ds.imaging.radiomics.profile.voxel_firstorder(
  bin_width = 25,
  kernel_radius = 2
)
```

## Arguments

- bin_width:

  Numeric; histogram bin width (default 25).

- kernel_radius:

  Numeric; voxel-neighborhood kernel radius.

## Value

A radiomics profile spec.
